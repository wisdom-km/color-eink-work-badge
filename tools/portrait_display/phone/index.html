更新与安全说明

只有整帧的长度、六色色码和 CRC 都通过校验后，显式刷新请求才会启动屏幕。上传中断不会启动新刷新；刷新一旦开始就无法安全取消。

这是单缓冲诊断程序，不保存上一帧 RAM 或 Flash 历史。重启后需重新上传。若刷新超时或掉电，屏面状态可能不完整，请检查工牌后重试。

此页面没有门禁卡、NFC凭证或第三方账号功能。请在匹配的新屏硬件上验证供电后使用。
